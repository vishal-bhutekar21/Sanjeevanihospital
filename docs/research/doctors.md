## 4. Operational Guardrails for Doctor Profiles

1. **No Hyperbolic Marketing**: Prohibit phrases like *"No. 1 Orthopedic in Jalna"* or *"Guaranteed 100% cure"*.
2. **Clear Availability Windows**: Each doctor will have configurable weekly schedules (e.g. Mon–Sat 10:00 AM – 01:00 PM) stored in the database.
3. **Transparent Consultation Fees**: Pre-defined fee schedules per doctor displayed upfront before payment.
